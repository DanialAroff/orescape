## Getting around

<CardGrid stagger>
	<Card title="Browse the vault" icon="open-book">
		Notes live under [`/vault`](/vault), mirroring your vault's folder structure in the sidebar.
	</Card>
	<Card title="Obsidian syntax, rendered" icon="pencil">
		`[[wikilinks]]`, `![[embeds]]`, `> [!callouts]`, and `==highlights==` render as you'd expect from Obsidian.
	</Card>
	<Card title="Point it at your vault" icon="setting">
		Set `OBSIDIAN_VAULT_PATH` in `.env` to publish any vault, or a folder within one.
	</Card>
	<Card title="How it's built" icon="external">
		See the [README](https://github.com/DanialAroff/orescape#readme) for how the vault loader and sidebar work.
	</Card>
</CardGrid>
